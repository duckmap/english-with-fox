# 1.2 — HiDPI, фанфары, движение

- Физическое разрешение вместо растяжения кадра 1280×800; учёт DeviceScaleFactor.
- Преобразование координат мыши/касания обратно в стабильную сетку 1280×800.
- TTF-текст в физическом размере, векторные панели с native-resolution кешем.
- Лисёнок и кубок 1024×1024; исходные малые иконки сглажены без заявления новой детализации.
- F11, светлые поля по краям, лимит внутреннего масштаба 3×.
- Фанфары один раз при завершении, независимый переключатель эффектов, приглушение музыки.
- Конфетти/танец/счёт при победе; мягкая анимация и сигнал при поражении.
- Непрерывное движение облаков, деформация хвоста и перемещение персонажей.
- Сохранения совместимы; добавлено поле effects с default=true.

# 1.1 — музыка и анимации

## Звук
- Встроена оригинальная музыкальная петля fox_garden.wav, 20 секунд, stereo PCM 16-bit / 44100 Гц.
- Громкость фоновой музыки — 0.20; во время речи — 0.035; на паузе — 0.08. Изменение громкости плавное, приглушение в начале слова — немедленное.
- Голос и музыка имеют независимые сохраняемые переключатели.
- Для замены композиции достаточно заменить assets/music/fox_garden.wav и пересобрать игру. Рекомендуется бесшовный WAV без тишины на стыке.
- tools/compose_music.py воспроизводит текущую композицию; нужен Python 3 и NumPy только для повторного рендера, не для запуска игры.

## Интерфейс
- Удалён StrokeRect, который добавлял прямоугольник при hover/focus.
- Hover: сглаженный подъём на 3 пикселя и масштаб 1.012. Нажатие: масштаб 0.985. Области нажатия стабильны и не зависят от анимации.
- Карточки тем появляются с короткой задержкой по порядку.
- Лисёнок слегка покачивается, подпрыгивает после верного ответа и мягко поворачивается после ошибки. Это трансформации существующих спрайтов, не новая покадровая анимация.
- Движение облаков, плавное заполнение прогресса, появление нового слова и мерцающие звёздочки при победе.
- Все анимации можно выключить кнопкой «Движение». В таком режиме hover/нажатия тоже не анимируются.
- Клавиатурный фокус обозначен маленькой точкой только после Tab.

## Совместимость
- Формат старого рейтинга, каталог сохранения и ключ localStorage не изменены.
- Добавлены поля music/motion; при отсутствии используются значения по умолчанию.
- Правила, темы, слова и начисление баллов не изменены.
