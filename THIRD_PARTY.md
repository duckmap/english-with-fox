# Сторонние компоненты

- Ebitengine и Go-модули: версии в go.mod/go.sum, тексты лицензий в licenses/.
- Go wasm_exec.js: BSD-style license проекта Go, приложена в licenses/Go/.
- Droid Sans Bold: The Android Open Source Project, Apache License 2.0; полная лицензия и уведомление в assets/fonts/NOTICE.
- Английские WAV-записи синтезированы eSpeak NG 1.51 (en-us, скорость 135). Сам движок и его библиотеки не распространяются с игрой. Проект eSpeak NG: https://github.com/espeak-ng/espeak-ng .
- Иллюстрации подготовлены в этой беседе по согласованному стилю; панели и кнопки без текста отрисованы отдельно. Шрифт не встроен в изображения надписей, а используется кодом игры.

- Музыкальная петля fox_garden.wav синтезирована специально для этого обновления из нот, без сторонних аудиозаписей.

- Звуки win.wav и try_again.wav синтезированы специально для версии 1.2, без сторонних аудиозаписей. Крупные спрайты лисёнка и кубка подготовлены заново в стиле проекта.
