# Угадай слово — English with Fox 1.2

Игра для детей 6–8 лет на **Go + Ebitengine 2.9.4** с подготовленными ранее спрайтами.


## Что нового в 1.2 — полноэкранный режим и живые персонажи

- Исправлено растягивание фиксированного кадра 1280×800: теперь 1280×800 — только координатная сетка интерфейса, а отрисовка выполняется в физическом разрешении с учётом масштаба монитора / Retina.
- Текст заново растеризуется из TTF в нужном размере. Кнопки и панели создаются векторной геометрией с антиалиасингом и кешируются **в текущем физическом разрешении**. Кеш пересоздаётся при смене размера/HiDPI; это не растягивание старых маленьких PNG.
- Новые крупные изображения лисёнка и кубка — 1024×1024. Небольшие исходные иконки сохранены по рисунку и подготовлены со сглаживанием; интерполяция не добавляет им новой художественной детализации.
- **F11** включает/выключает полноэкранный режим. Максимизация окна тоже обрабатывается. Пропорции интерфейса сохраняются, свободные поля — светлые. Целевая чёткость — до 4K; внутренний масштаб ограничен 3× (3840×2400), чтобы не создавать неограниченные GPU-буферы на 5K/8K.
- Победа: отдельная фанфара, конфетти, танец лисёнка, движение кубка и анимированный счёт. Поражение: мягкий короткий звуковой сигнал, поддерживающее движение персонажа и поднимающиеся звёзды.
- Облака непрерывно перемещаются по небу. Лисёнок появился в меню, двигается в игре и на результате; хвост деформируется отдельно от тела.
- Новый переключатель **«Эффекты»** управляет звуками результата отдельно от голоса и музыки. Все четыре настройки доступны на паузе. Музыка приглушается и под фанфару.

Если в прежней версии вы отключили «Движение», настройка сохранится: включите её, чтобы увидеть анимации. Системное уменьшение движения по-прежнему учитывается.

**Обновляйте папку целиком**, не только main.go: добавлены render.go, character.go, result.go, internal/view и новые ассеты. Из исходников: `go run .` или RUN_SOURCE_WINDOWS.bat. Готовая игра: PLAY_WINDOWS.bat. Рейтинг и имя используют прежнее хранилище и не сбрасываются обновлением.

## Что нового в 1.1

- Фоновая музыка: оригинальная мягкая 20-секундная петля, встроенная в игру.
- Музыка включается и выключается отдельно от произношения. Во время слова она автоматически приглушается; на паузе звучит тише. Переключатель есть в меню и в окне паузы.
- Убрана прямоугольная рамка при наведении. Вместо неё — небольшой плавный подъём кнопки и мягкое нажатие. Для клавиатурной навигации Tab оставлена маленькая точка, а не рамка.
- Плавное появление карточек тем, анимация кнопок, движение облаков, покачивание и реакция лисёнка, плавный прогресс, появление нового слова и звёздочки на экране победы.
- Кнопка **«Движение»** отключает анимации. В браузере системная настройка уменьшения движения учитывается по умолчанию; ручной выбор запоминается.
- Старые имя, рейтинг и настройка голоса сохраняются: используется прежний файл/ключ хранилища. Две новые настройки при загрузке сохранения старой версии получают значения по умолчанию.

**Обновление:** распакуйте новую версию в отдельную папку целиком. Не заменяйте только main.go: добавлены music.go, effects.go и музыкальный WAV. Из исходников запускайте именно `go run .`, не `go run main.go`. В Windows можно использовать `RUN_SOURCE_WINDOWS.bat`.

## Быстрый запуск

### Windows 10/11, x64 — без установки Go и Python
1. Полностью распакуйте ZIP.
2. Запустите `PLAY_WINDOWS.bat` или `build/WordGame.exe`.

EXE собран из приложенного кода, но не подписан цифровой подписью. Сборка для Windows прошла; запуск на Windows в среде подготовки не проверялся. Если политика устройства запрещает неизвестные приложения, используйте браузерную версию или соберите проект самостоятельно, не отключая защиту.

### Браузер — готовая WebAssembly-сборка
1. Нужен Python 3.
2. В каталоге проекта выполните:

```sh
python START_SERVER.py
```

На macOS/Linux команда может называться `python3`. Сервер откроет `http://localhost:8080`; нажмите **«Играть!»**. Если вкладка не открылась автоматически, введите этот адрес вручную. Не открывайте `web/index.html` через file://: WebAssembly нужно отдавать через HTTP. Сервер слушает только ваше устройство. Для остановки — Ctrl+C.

Go и интернет для запуска готовых сборок не нужны. Все спрайты, шрифт и аудиозаписи включены. На телефоне удобнее горизонтальный режим; интерфейс прежде всего рассчитан на компьютер и планшет, не на маленький портретный экран.

## Правила
- Выберите одну из **12 тем**. В каждой **30 слов**, всего **360 карточек**.
- Порядок слов и расположение пяти ответов случайные. Слова в одной попытке не повторяются.
- Английское слово показывается и автоматически озвучивается. Динамик повторяет произношение.
- Стартовый счёт — **10**. Верно — **+1**, ошибка — **−2**.
- После ответа правильный вариант подсвечивается на 1,5 секунды; повторные клики не начисляют баллы.
- **Победа:** все 30 слов пройдены и счёт больше нуля. Максимум — **40**.
- **Поражение:** счёт достиг нуля или ниже. На экране он ограничивается нулём.
- Новая попытка снова начинается с 10 баллов.
- При выходе из незавершённой попытки результат не записывается.

## Управление
- Мышь или касание — выбор темы, ответа и кнопок.
- **1–5** — варианты ответа слева направо, затем нижний ряд.
- **Пробел** — повторить слово.
- **Esc** — пауза/продолжение; на других экранах — к темам.
- **Tab → Enter** — переход по кнопкам и активация.
- Нажмите на поле имени в меню, удалите старое имя Backspace и введите своё; Enter сохраняет. До 18 символов. На компьютере поддерживается ввод кириллицы через обычную раскладку клавиатуры; поле не является полноценным мобильным IME-редактором.

## Рейтинг и сохранение
Рейтинг **локальный**, не сетевой. Для нескольких детей можно менять имя перед попыткой.

Сохраняются 50 лучших завершённых попыток: имя, тема, счёт, верные ответы, ошибки, дата и факт прохождения. Сортировка: баллы по убыванию, затем верные ответы, затем более новая попытка. В таблицу входят и проигранные попытки.

- Windows: `%APPDATA%/english-with-fox/profile.json`.
- Linux: пользовательский config-каталог, обычно `~/.config/english-with-fox/profile.json`.
- macOS: `~/Library/Application Support/english-with-fox/profile.json`.
- Браузер: `localStorage`, ключ `english-with-fox.profile.v1`, отдельно для каждого адреса сайта/порта. Инкогнито и очистка данных браузера могут удалить рейтинг.

Если хранилище недоступно, игра показывает сообщение. Аккаунты, облачная синхронизация и общий рейтинг между устройствами не реализованы.

## Сборка из исходников
Нужен **Go 1.25.3 или новее**. Зависимости зафиксированы в `go.mod` / `go.sum`; при первой установке нужен интернет. Для Linux потребуются системные библиотеки и заголовки X11/OpenGL/ALSA согласно требованиям Ebitengine для вашего дистрибутива.

```sh
go mod download
go test -race ./internal/quiz
go run .
```

Windows x64 (из любой поддерживаемой среды Go):

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags="-s -w -H=windowsgui" -o build/WordGame.exe .
```

Эта запись переменных — для shell macOS/Linux; для PowerShell используйте `$env:GOOS="windows"`, `$env:GOARCH="amd64"`, `$env:CGO_ENABLED="0"` отдельно перед `go build`.

Браузер:

```sh
GOOS=js GOARCH=wasm go build -o web/game.wasm .
```

Скопируйте `wasm_exec.js` из `$(go env GOROOT)/lib/wasm/` в `web/` **из той же версии Go**, которой собираете WASM. Затем запустите `START_SERVER.py`. Сборки используют обычные файлы PNG; исходный атлас предыдущего набора этому проекту не нужен.

## Структура

```
main.go                    экраны, управление, рендер, озвучивание
music.go                   зацикленная музыка и приглушение при речи
effects.go                 плавные анимации элементов
render.go                  HiDPI, векторные формы, native-resolution кеш
character.go               движения лисёнка и отдельная деформация хвоста
result.go                  анимация результата и фанфары
storage_native.go          сохранение настольной версии
storage_js.go              браузерный localStorage
internal/quiz/             правила и unit-тесты без графики
internal/view/             расчёт разрешения и тесты HiDPI
assets/data/topics.json    12 тем по 30 пар en/ru
assets/topics/             иконки тем
assets/fox/                три статические позы лисёнка
assets/ui/                 кнопки и иконки
assets/fonts/              кириллический шрифт и лицензия
assets/music/              музыкальная петля: stereo WAV, 44100 Гц
assets/sfx/                фанфара победы и звук повторной попытки
assets/audio/              WAV-файлы и index.json
web/                       готовая браузерная игра
build/WordGame.exe         готовая сборка Windows x64
licenses/                  лицензии сторонних компонентов
```

Для изменения слов редактируйте `topics.json`, оставляя 30 уникальных английских слов и 30 уникальных переводов в каждой теме. Отвлекающие ответы выбираются из той же темы. «Цвета и формы» объединены, чтобы получить 30 осмысленных карточек.

Для нового слова добавьте его WAV и запись в `assets/audio/index.json`: ключ — точное английское написание, значение — имя WAV. Текущие записи — синтетическое американское английское произношение eSpeak NG 1.51; не профессиональная дикторская запись. WAV: PCM 16-bit, mono, 22050 Гц; Ebitengine приводит к 44100 Гц при проигрывании. Есть 359 уникальных записей для 360 карточек: одно английское слово используется в двух темах. Бинарники синтезатора в архив не входят.

После изменения любых встроенных ассетов заново соберите WASM/EXE. Лисёнок меняет статические позы; скелетная/покадровая анимация не реализована.

## Проверки
Подробности — `TESTING.md`. Файлы `debug_e2e.go` используются только при сборке с тегом `e2e` для чтения состояния браузерными тестами. В обычной сборке API диагностики отсутствует.

## Настройка внешнего вида 1.2

Цвета и скругления кнопок меняются в render.go; старые PNG кнопок оставлены как исходные референсы и больше не используются как фон UI. Крупные персонажи — PNG из assets/fox/, кубок — assets/ui/trophy.png. В character.go реализована деформация сетки и перемещение целого персонажа; это не новая скелетная или покадровая анимация. Скорость облаков задаётся в background() main.go.
